# Трасування між лабораторними та відомі розбіжності

Проєкт SafeStep описано у двох дисциплінах, і кожна дивиться на нього з різного боку:

- **«Аналіз вимог до ПЗ»** описує **цільовий продукт** (product vision): AI-помічник, адаптивна траєкторія, Real-to-Drill, мультиканальність. Вимоги мають ID **FR1–FR10**.
- **«Економіка ПЗ»** оцінює **MVP** — мінімальну першу версію, з якої свідомо вилучено ШІ-генерацію, ML-персоналізацію й рейтинги. Функції мають ID **F1–F10**.

Тож це не суперечність, а два етапи: **MVP (реліз 1) → цільовий продукт (реліз 2+)**. Таблиця нижче показує, як вони співвідносяться.

## 2. Нефункціональні вимоги

| NFR | Аналіз вимог (цільовий продукт) | Економіка (MVP) | Різниця |
|---|---|---|---|
| NFR1 Продуктивність | дашборд ≤ 2 с при 1000 користувачів; Кібер-коуч ≤ 30 с | дашборд ≤ 2 с при 1000 користувачів | + вимога до AI |
| NFR2 Доступність | ≥ 99,5%; MTTR ≤ 30 хв; ручний режим без AI | ≥ 99,5% | + MTTR і деградація AI |
| NFR3 Безпека | TLS 1.2+, AES-256, дані в ЄС, без навчання AI на даних клієнтів, 100% PII видаляється | TLS 1.2+, AES-256, логування доступів, 2 ролі | різні акценти — варто об'єднати |
| NFR4 | Етичність **і** зручність, WCAG 2.1 AA | Етичність | у MVP зручність — окрема NFR5 |
| NFR5 | Локалізація: українська + англійська | Зручність (мікроурок ≤ 3 хв) | ⚠️ у MVP мультимовність понад українську **поза scope** |

## 3. Архітектура (ЛР 3) і кошторис

Діаграми компонентів і розгортання в ЛР 3 «Аналізу вимог» описують **цільовий продукт**: там є `AdaptiveEngine`, `CoachService`, `AIGateway`, `TelegramBot`. Кошторис, TCO і NPV з «Економіки» рахують **лише MVP** (F1–F10). Тому вартість AI-компонентів і LLM API в економічній моделі не врахована — це треба мати на увазі, якщо оцінювати цільовий продукт.

## 4. Ланцюг чисел в «Економіці ПЗ»

```
scope F1–F10 (ЛР 1)
  → effort: P50 122,5 роб. дня, baseline 130 (ЛР 2)
  → labor 62 512 € → cost baseline MVP 86 572 € (ЛР 3)
  → тарифи 209 / 649 / 2 290 € → ARPU 8,21 €, GM 72,2% (ЛР 4)
  → CAC 40 €, LTV/CAC 2,47, break-even 2 359 / 3 593 учнів (ЛР 5)
  → CF₀ 220 000 €, NPV base −532 605 € (ЛР 6)
  → портфель контролю якості 7 750 € (ЛР 7)
  → рішення STOP; NPV = 0 лише при ARPU ≈ 21,90 € (ЛР 8)
```

Ланцюг відтворює скрипт [`model/safestep_model.py`](../model/safestep_model.py): 22 ключові показники ЛР 2, 4, 5, 6 збігаються зі звітами.
